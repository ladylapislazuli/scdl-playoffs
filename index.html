Methodology

Unpicked games

Any game you haven't picked is a coin flip. The odds count every possible result.

Ties

Head-to-head record between the tied teams, per Rule 4.4. If that only splits them into smaller ties, it runs again on each group.

Win time

Still even? Whoever won their head-to-head games fastest on average ranks higher. No tiebreaker games. Until those games are played, it's a coin flip.
